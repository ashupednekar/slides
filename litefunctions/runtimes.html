Static langs
  • Compile to binaries
  • Low startup time
  • Low memory usage
  • → One runtime per function
Dynamic languages
  • High memory usage
  • Slow startup
  • → One runtime per project (not one per function)
  • Hot reload — the one amazing superpower dynamic languages have, so we load the function code into a preexisting project runtime (p.s. dll's/wasm could work 😉)
